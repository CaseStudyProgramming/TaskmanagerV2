Advanced Task Manager API (1.0.0)

Download OpenAPI specification:

Development Team: dev@taskmanager.example License: MIT

API for the Advanced Task Manager application. This API provides task management functionality with support for authenticated and guest users, offline mode, export/import capabilities, and smart prioritization.

Tasks

Task management operations

List tasks

Retrieves a paginated list of tasks for the authenticated user. Supports filtering by status, priority, due date, and search.

Authorizations:
BearerAuth
query Parameters
status
string
Enum: "todo" "in-progress" "completed"

Filter by task status

priority
string
Enum: "low" "medium" "high" "urgent"

Filter by task priority

search
string

Search in title and description

due_date_from
integer <int64>

Filter tasks due after this date (epoch milliseconds)

due_date_to
integer <int64>

Filter tasks due before this date (epoch milliseconds)

tags
string

Filter by tags (comma-separated)

sort_by
string
Default: "created_at"
Enum: "due_date" "priority" "created_at" "priority_score"

sort_order
string
Default: "desc"
Enum: "asc" "desc"

Sort order

page
integer >= 1
Default: 1

Page number

limit
integer [ 1 .. 100 ]

Items per page

BearerAuth

required
required
